FRC CAN Extended Arbitration ID (29-bit)
Every CAN frame targeting a SPARK controller uses a 29-bit extended ID. Build it as:

arb = (DevType<<24) | (Manufacturer<<16) | (APIClass<<10) | (APIIndex<<6) | DeviceID

USB-Serial Direct Connection
The SPARK MAX/Flex exposes a CDC USB-Serial port. Settings: 115200 baud, 8N1. The protocol mirrors CAN exactly but uses a fixed 12-byte packet per transaction. Every command sent over USB receives a 12-byte response — even commands that don't respond over CAN will receive an Ack.
Communication Path
💻 Host (Python / PC)your application
↕
🔌 USB-C cableCDC serial · 115200 baud · 8N1
↕
⚡ SPARK MAX / Flexno CAN adapter needed
Note: If the controller was previously on a roboRIO CAN bus, a safety lockout blocks USB comms. Power-cycle after disconnecting from CAN to release it.
Outbound Packet — Host → Controller (12 bytes)
The 32-bit Command ID is packed little-endian into bytes 0–3. The Device ID field is DNC (ignored) when connected directly via USB — the command targets whichever device is physically plugged in.

Python Construction Example
# Build and send a 12-byte USB packet: set duty cycle +0.5 on device 1 import struct, serial ser = serial.Serial('/dev/ttyUSB0', baudrate=115200, timeout=0.1) # ── Assemble the 32-bit Command ID ───────────────────── cmd_id = ( (0x02 << 24) | # Device Type: Motor Controller (0x05 << 16) | # Manufacturer: REV Robotics (0x00 << 10) | # API Class: Control (0x00) (0x00 << 6) | # API Index: Setpoint (0x00) 0x01 # Device ID: 1 (DNC for direct USB) ) # ── Build the 8-byte data payload ────────────────────── payload = struct.pack('<fBBxx', 0.5, # float32: setpoint value 0, # uint8: control type (0=duty cycle) 0 # uint8: PID slot (0–3) ) # xx = 2 padding bytes → total 8 # ── Combine into final 12-byte packet ────────────────── packet = struct.pack('<I', cmd_id) + payload # 4 + 8 = 12 bytes ser.write(packet) response = ser.read(12) # always read 12 bytes back # ── Parse response Command ID ────────────────────────── resp_id = struct.unpack_from('<I', response, 0)[0] resp_type = (resp_id >> 29) & 0x7 # 0=Ack, 1=Data resp_data = response[4:] # 8 bytes of payload
